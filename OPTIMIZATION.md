# Объяснение оптимизации алгоритма факториала

## Исходный вариант - рекурсивный
## Улучшенный вариант - итеративный

## Почему новый вариант лучше?

### 1. Производительность
- Рекурсивный подход требует O(n) времени и O(n) памяти
- Итеративный подход требует O(n) времени и O(1) памяти
Преимущество итеративного подхода в меньшем потреблении ресурсов по памяти

### 2. Безопасность
- Рекурсивный подход может вызвать переполнение стека (RecursionError) при больших n
- Итеративный подход безопасен для любых разумных значений n

### 3. Читаемость
- Итеративный код проще для понимания
- Меньше вероятность ошибок

## Вывод
Итеративный алгоритм предпочтительнее для вычисления факториала благодаря лучшей производительности, безопасности и простоте.
